# Retail Stock Picker — 散户纪律选股

## 四条铁律（不可违反）

> 这四条是该 Skill 的底层逻辑，任何输出结论都必须遵守：

1. **情绪门控**：市场情绪❌退潮时，直接输出"今日空仓"，不分析任何股票
2. **只买主线龙头**：候选标的必须来自当日确认主线板块，热搜消息股、孤立题材股一律排除
3. **严格止损**：每个候选标的必须标注止损价（实际成交价×0.97），亏损达3%必须卖出
4. **不满仓**：总仓位上限为本金×70%（`meta.max_position`），留30%现金缓冲；单只股票最多占可用仓位的72%

## AI 分析框架

### 第一步：情绪门控（必须先过这关）

| 指标 | 字段来源 | 判断标准 |
|------|---------|---------|
| 涨停家数 | `market.updown` | <15家 → 退潮 |
| 跌停家数 | `market.updown` | >20家 → 退潮 |
| 上涨占比 | `market.changedist` | <45% → 退潮 |

| 情绪等级 | 条件 | 操作指令 |
|---------|------|---------|
| ✅ 活跃 | 涨停≥30家，上涨占比≥55%，跌停≤10家 | 正常执行后续步骤 |
| ⚠️ 分歧 | 涨停15~30家 或 上涨占比45%~55% | 仓位减半（`max_position ÷ 2`），只操作评分最高的1只 |
| ❌ 退潮 | 涨停<15家 **或** 跌停>20家 | **立即终止，输出"今日空仓"** |

---

### 第二步：找主线板块

从 `sector.ranking` 中找**双上榜板块**（涨幅榜 + 资金流入榜同时在列）：

- 双上榜 + 热搜榜也在 → **确认主线**，进入第三步
- 仅涨幅榜 → **候选主线**，降低置信度
- 无双上榜板块 → 输出"今日无明确主线，建议观望"，终止分析

取确认主线中涨幅**排名第一**的板块作为核心板块（最多分析2个）。

#### 板块整体涨幅过滤

对进入候选的每个主线板块，读取 `sector.ranking` 中该板块今日整体涨幅：

| 板块今日涨幅 | 处理 |
|------------|------|
| < 3% | 正常，成份股次日仍有上涨空间 |
| 3%~5% | 标注"板块今日中等涨幅，次日注意高开兑现" |
| > 5% | **降级为候选**，标注"板块今日已大涨，次日高开兑现风险高，谨慎操作" |
| > 8% | **排除**，板块当日亢奋，次日大概率获利了结 |

---

### 第三步：从主线板块找龙头

从 `stocks.quotes` 批量行情中筛选主线板块成份股，按以下条件评分：

#### 前置过滤（不满足直接排除，不进入评分）

| 过滤条件 | 说明 |
|---------|------|
| 总市值 < 30亿 | 流动性风险，散户难出货，排除 |
| 总市值 > 500亿 | 大盘股短线弹性小，排除 |
| 今日涨幅在板块内排名后50% | 从 `stocks.quotes` 读 `changePercent`，对板块内所有成份股按今日涨幅降序排列，只取前50%进入评分 |

> ⚠️ **重要**：`sector constituent` 返回的成份股顺序是按市值排列的，不代表今日涨幅强弱。AI 必须从 `stocks.quotes` 中读取每只股票的 `changePercent` 字段，自行在板块内按涨幅降序排序，只取前50%的标的进入后续评分。

#### 龙头评分标准

| 条件 | 权重 | 说明 |
|------|------|------|
| 量比 > 1.5 | +30分 | 放量上涨，有资金介入 |
| 换手率 3%~15% | +20分 | 活跃但不过热 |
| 今日大涨 5%~9.9%（未涨停） | +25分 | 强势有分歧，次日看开盘方向 |
| 今日涨停 | +15分 | 筹码锁定，但需结合位置判断（高位涨停反而危险） |
| 近5日涨幅 < 15% | +10分 | 位置不高，未透支 |
| 近5日涨幅 15%~25% | 0分 | 中性 |
| 近5日涨幅 > 25% | -30分 | **位置过高，散户接盘风险大** |
| MACD 金叉向上（来自 `stocks.technicals`） | +15分 | 技术共振 |
| 股价在20日均线上方（来自 `stocks.klines` 22根K线计算） | +10分 | 趋势向上 |
| 股价在52周高点85%以上（来自 `stocks.quotes` `high52week`） | -20分 | 高位压力大 |
| 总市值 30~100亿 | +10分 | 最适合散户的中小盘弹性好 |

**评分 ≥ 50分** 才进入候选清单。

---

### 第四步：生成操作方案

对每个候选标的，输出以下**完整操作参数**：

#### 仓位分配规则

从 `meta.max_position`（= capital × 0.7）和 `meta.cash_buffer`（= capital × 0.3）读取：

| 候选数量 | 单只仓位上限 | 说明 |
|---------|------------|------|
| 1只 | `max_position × 0.72`（约5000/7000） | 留约28%备用防追加 |
| 2只 | `max_position ÷ 2` | 平均分配 |
| 3只及以上 | 只取评分最高的2只 | 散户精力有限，不超过2只 |

#### 买入方式（散户不参与竞价，等开盘确认）

> ⚠️ 散户不参与竞价买入。竞价阶段（9:15~9:25）只**观察**，不下单。

| 今日状态 | 次日买入方式 | 放弃条件 |
|---------|------------|---------|
| 今日涨停 | 开盘后5分钟确认：开盘价在昨收 +0%~+3% 区间内再买入 | 高开 >3% 或开盘跌破昨收，放弃 |
| 今日大涨5~9.9%（未涨停） | 开盘低开或平开（昨收 -2%~0%）时买入；小幅高开（0~+2%）等回调至昨收附近再买 | 高开 >2% 不追，直接放弃 |
| 今日普通上涨（<5%） | 开盘价在昨收 ±1% 以内时买入 | 高开 >1% 或低开 >1%，放弃 |

#### 每只股票必须输出的参数

| 参数 | 计算方式 | 说明 |
|------|---------|------|
| 参考买入价 | 今日收盘价（仅参考） | 实际以次日成交价为准 |
| 买入金额 | 按仓位分配（动态） | 从 `meta.max_position` 计算 |
| 可买股数 | 买入金额 ÷ 参考买入价（取整百股） | 实际数量以成交价调整 |
| **止损价** | **实际成交价 × 0.97** | ⚠️ 必须等成交后再设，不能用今日收盘价预算 |
| **止损纪律** | **亏损达3%立即卖出，不找理由** | 这是保护本金的唯一手段 |
| 止盈参考 | 实际成交价 × 1.05 | 盈5%考虑减半仓，不要一把梭出 |
| 最大亏损估算 | 买入金额 × 3% | 基于参考买入价的估算，供风险评估 |
| 放弃条件 | 见买入方式表格 | 不满足条件坚决不买 |

## 五、次日盯盘要点

**开盘前（9:00~9:14）**
- 查候选股有无重大公告（利空直接放弃）
- 今日重要宏观事件：{macro_calendar 中的事件}

**竞价阶段（9:15~9:25）**
- 只观察，不下单
- 竞价高开 > 3%，直接放弃该标的

**开盘后5分钟（9:30~9:35）：实时验证**

对每只候选股，运行 stock-sentiment 脚本做实时状态确认：

```bash
python3 ~/.codebuddy/skills/stock-sentiment/scripts/collect_sentiment.py {股票代码}
```

对照以下四项，全部通过才买入，任一失败立即放弃：

| 验证项 | 通过条件 | 失败条件 | 数据字段 |
|--------|---------|---------|---------|
| 开盘价位 | 开盘价在昨收 ±3% 以内 | 高开 >3% 或直接低开跌破昨收 | `round1.quote` → `open` vs `prevClose` |
| 量比 | 开盘量比 ≥ 1.0（资金仍在） | 量比 < 0.8（缩量，资金撤退） | `round1.quote` → `volumeRatio` |
| 主力资金 | 主力净流入为正 或 超大单净买 | 超大单净卖出（大资金出货） | `round1.fund_flow` |
| 板块状态 | `round1.hot_sector` 中该股所属板块仍在热搜前列，且 `round1.sse_index` 大盘未急跌 | 大盘急跌 >1.5% 或股票所属板块从热搜消失 | `round1.hot_sector` + `round1.sse_index` |

> ⚠️ **板块状态说明**：`stock-sentiment` 不采集实时板块涨幅榜，无法直接判断板块是否仍在涨幅排名前列。替代方案：用 `hot_sector` 判断板块热度是否仍在，结合大盘方向综合判断。若需精确判断板块涨幅，可额外运行 `westock sector ranking` 查看实时榜单。

**买入后立即设置止损**：实际成交价 × 0.97，这是铁律

**持仓中（9:35 之后）**
- 若主力资金转为持续净流出 → 不论盈亏，考虑离场
- 若所属板块出现多只个股跳水 → 板块退热信号，止盈离场

---
> ⚠️ 本报告仅基于数据客观分析，不构成投资建议。严格执行止损是保护本金的唯一方式。
```

## 与 hotmoney-scanner 的区别

| 对比项 | hotmoney-scanner | retail-stock-picker |
|--------|-----------------|---------------------|
| 目标用户 | 游资视角（观察游资行为） | 散户（1万以内真实操作） |
| 核心数据 | 龙虎榜游资席位 | 主线板块成份股行情+技术 |
| 仓位管理 | 不涉及 | 明确给出买入金额、止损价 |
| 止损规则 | 无 | 强制3%止损 |
| 操作频率 | 每日 | 每日，但情绪退潮直接跳过 |

## 异常处理

| 情况 | 处理 |
|------|------|
| `data.error` 存在 | 非交易日，直接输出提示 |
| 情绪❌退潮 | 终止分析，输出"今日空仓" |
| 无双上榜主线板块 | 输出"今日无明确主线，建议观望" |
| 主线成份股均评分<50 | 输出"主线标的质量不足，今日观望" |

## 盘中实时验证（stock-sentiment 联动）

> 本 Skill 的收盘后选股给出"候选股"，次日开盘后通过 `stock-sentiment` 做实时状态验证，决定最终是否买入。

### 使用方式

```bash
# 对昨晚报告中的候选股做开盘实时检查（9:30 之后运行）
python3 ~/.codebuddy/skills/stock-sentiment/scripts/collect_sentiment.py {股票代码或名称}
```

### 四项核心验证（全部通过才买，任一失败放弃）

| # | 验证项 | 通过 | 放弃 | 读取字段 |
|---|--------|------|------|---------|
| 1 | **开盘价位** | 开盘价在昨收 ±3% 以内 | 高开 >3% 或直接低开破昨收 | `round1.quote` → `open` / `prevClose` |
| 2 | **实时量比** | ≥ 1.0（资金仍在介入） | < 0.8（缩量，资金撤退信号） | `round1.quote` → `volumeRatio` |
| 3 | **主力资金方向** | 主力净流入为正，或超大单净买 | 超大单净卖出（大资金出货） | `round1.fund_flow` |
| 4 | **板块&大盘状态** | 所属板块仍在热搜前列，且大盘未急跌 | 大盘急跌 >1.5%，或板块从热搜消失 | `round1.hot_sector` + `round1.sse_index` |

> ⚠️ 如需精确判断板块实时涨幅，可额外运行：`westock sector ranking`

### 持仓期间的止损信号

买入后持续观察，出现以下任一信号考虑离场：

| 信号 | 操作 |
|------|------|
| 股价跌破止损价（成交价 × 0.97） | 立即止损，不等待 |
| 主力资金持续净流出超过30分钟 | 止盈或止损离场 |
| 所属板块出现多只股票快速跳水 | 板块退热，止盈离场 |
| 大盘急跌超 1.5% | 优先保本，考虑离场 |

### 止盈信号

| 信号 | 操作 |
|------|------|
| 股价达到成交价 × 1.05（+5%） | 减半仓，剩余部分移动止损至成本价 |
| 股价达到成交价 × 1.10（+10%） | 全部卖出，不贪 |
| 次日持仓且个股已明显走弱（量缩价跌、板块退热） | 择机止盈，不强求持有 |

> 本 Skill 定位是"今天买、明天卖"的短线策略，**不强制当日清仓**。持股1~2日为主，超过2日若无新的买入理由应主动离场。
