# Stock Sentiment —股票市场情绪分析

## 前置依赖

本 Skill 依赖 `westock` CLI（数据源）和 Python 3（采集脚本）。

```bash
# 安装 westock（已安装可跳过）
bash ~/.codebuddy/skills/westock-data/scripts/setup.sh

# 验证
westock --help
python3 --version
```

---

## 使用方式

### 第一步：调用 Python 脚本采集数据

```bash
# 用股票名称
python3 ~/.codebuddy/skills/stock-sentiment/scripts/collect_sentiment.py 盛达资源

# 用股票代码
python3 ~/.codebuddy/skills/stock-sentiment/scripts/collect_sentiment.py sz000603

# 将结果保存到文件（数据量较大时推荐）
python3 ~/.codebuddy/skills/stock-sentiment/scripts/collect_sentiment.py 贵州茅台 > /tmp/sentiment_data.json
```

脚本自动完成：
- **Phase 0**：名称自动解析为代码（调用 `westock search`）
- **第一轮（14条命令并行）**：行情、K线、技术指标、资金流向、新闻、财报、热搜、大盘、板块热度、中美宏观、美股港股指数
- **第二轮（A股专用，2条并行）**：龙虎榜、北向持仓
- **第三轮（A股专用）**：从hot_sector匹配所属板块，查行业估值对标

返回 JSON：
```json
{
  "meta": { "code": "sz000603", "is_ashare": true, "sector_code": "pt01801054", "collected_at": "..." },
  "round1": { "quote": "...", "kline": "...", "technical": "...", ... },
  "round2": { "lhb": "...", "north_holding": "..." },
  "round3": { "sector_valuation": "..." }
}
```

### 第二步：AI 进行六维分析

拿到 JSON 数据后，按以下框架逐维度打分并生成报告。

---

## 六维分析框架

| 维度 | 权重 | 数据字段 | 核心问题 |
|------|------|----------|----------|
| 价格与量价 | 22% | `round1.quote` + `round1.kline` |涨跌幅、换手率、量比+方向、振幅、K线趋势 |
| 技术指标 | 18% | `round1.technical` | MACD/KDJ/RSI/BOLL/均线排列|
| 资金流向 | 22% | `round1.fund_flow` + `round2.lhb` + `round2.north_holding` | 主力进出、龙虎榜席位、北向动向 |
| 新闻舆情 | 14% | `round1.news` + `round1.hot_stock` | 标题情绪、热搜热度|
| 估值与基本面 | 14% | `round1.quote`(PE/PB) + `round1.finance` + `round3.sector_valuation` | 行业估值对比、财报增长 |
| 外部环境 | 10% | `round1.sse_index` + `round1.hot_sector` + `round1.cn_pmi/cn_lpr/us_inflation/us_monetary` + `round1.global_index` | 大盘、板块热度、中美宏观、美股港股指数 |

### 维度 1：价格与量价（22%）

| 指标 | 看多 | 看空 | 中性 |
|------|------|------|------|
| 涨跌幅 | >+3% | <-3% | ±3%以内 |
| 换手率 | 5%~15% 活跃 | >25% 出货 / <1% 冷清 | 1%~5% |
| 量比+方向 | 量比>1.5 且阳线（放量上涨） | 量比>1.5 但涨幅<1%或阴线（放量滞涨/下跌） | 量比 0.8~1.5 |
| 振幅 | 3%~8% | >12% 剧烈分歧 | <3%无方向 |
| K线趋势 | 多头排列，连阳| 空头排列，连阴 | 横盘震荡 |
| 近期涨幅 | 5日<15%温和，或趋势性上涨 | 5日>20%且非趋势行情（短期透支） | - |

> **趋势性行情判定**：30日K线多头排列 + 20日涨幅持续温和放大 → 短期超涨不作为主要负面信号。

**评分**：60为中性基准，综合信号偏多则>60，偏空则 <60。

### 维度 2：技术指标（18%）

| 指标 | 看多 | 看空 |
|------|------|------|
| MACD | DIF>DEA，金叉，红柱放大 | DIF<DEA，死叉，绿柱放大 |
| KDJ | K>D，低位（K<30）金叉 | K<D，高位（K>80）死叉 |
| RSI | 40~70 温和偏强 | >80 超买 / <20 超卖 |
| BOLL | 价格沿上轨运行| 跌破中轨或沿下轨运行 |
| 均线 | 短期在长期上方，多头排列 | 短期下穿，空头排列 |

**评分**：5 项计票，每项看多 +20/ 中性 +12 / 看空 +4。
> KDJ 超买需结合 K/D 交叉方向，不能只看数值；RSI 超卖阈值 <20（不是<30）。

### 维度 3：资金流向（22%）

| 指标 | 看多 | 看空 |
|------|------|------|
| 主力净流入（当日/近5日/近20日） | 持续大额净流入 | 持续大额净流出 |
| 超大单 | 超大单净买| 超大单净卖 |
| 龙虎榜席位 | 知名游资/机构净买，分歧小 | 机构净卖，深股通大额卖出，席位分歧大 |
| 北向持仓 | 季度增持趋势 | 季度减持 + 短线龙虎榜卖出 |

**降级规则**：无龙虎榜当日数据 → 只看 fund_flow；无北向数据 → 只看 fund_flow + lhb。

### 维度 4：新闻舆情（14%）

- 正面关键词：涨停/大增/突破/利好/业绩增长/获批→ 每条+8分（满分 100，基准 60）
- 负面关键词：暴跌/亏损/减持/监管/问询/跌停/立案 → 每条 -10 分
- 在热搜榜 → +5 分热度加成
- 中性新闻不加减

### 维度 5：估值与基本面（14%）

1. **行业对标**（优先，来自 `round3.sector_valuation`）：
   - 个股PE/PB < 行业均值 → 偏多（低估）
   - 个股 PE/PB > 行业均值 50%+ → 偏空（高估）
   - 无行业数据 → 仅绝对值参考，该子项权重减半
2. **财报增长**：营收/净利润同比增长 → 偏多；下滑 → 偏空
3. **ROE**：>15% 优秀加分；<5% 偏空减分

### 维度 6：外部环境（10%）

| 指标 | 看多 | 看空 | 数据字段 |
|------|------|------|----------|
| A股大盘（上证） | 上涨 + 量能放大 | 下跌 /缩量 | `round1.sse_index` |
| 板块热度 | 所属板块 hot_sector 排名前15，涨幅>2% | 未上榜或跌幅 | `round1.hot_sector` |
| 中国宏观 | PMI>50 / LPR下调 | PMI<50 /流动性收紧 | `round1.cn_pmi` / `round1.cn_lpr` |
| 美国宏观 | 通胀回落 / 降息预期 | 通胀顽固 / 加息预期 | `round1.us_inflation` / `round1.us_monetary` |
| 美股/港股 | 纳指/道指前日上涨，港股今日上涨 | 外围前日大跌（次日A股低开压力） | `round1.global_index`（usIXIC/usDJI/hkHSI/hkHSTECH） |

> westock 支持 `usIXIC`（纳指）、`usDJI`（道指）、`hkHSI`（恒生）、`hkHSTECH`（恒生科技），**不支持** `usSPX`（标普500）。

## 综合评分规则

**总分 = Σ(维度评分 × 权重)**

| 总分 | 情绪等级 | 含义 |
|------|----------|------|
| 80~100 | 🔥 极度乐观 | 多项指标共振看多，情绪亢奋 |
| 65~79 | 😊 偏乐观 | 整体偏多，有资金关注 |
| 45~64 | 😐 中性 | 多空平衡，无明显方向 |
| 30~44 | 😟 偏悲观 | 整体偏空，抛压或观望 |
| 0~29 | ❄️ 极度悲观 | 多项指标共振看空，情绪恐慌 |

## 异常处理

| 情况 | 处理 |
|------|------|
| westock 未安装 | 执行 `bash ~/.codebuddy/skills/westock-data/scripts/setup.sh` |
| 脚本找不到股票代码 | 检查名称拼写，或直接传`sh/sz/bj` 前缀代码 |
| round2 为空（非A股） | 跳过龙虎榜和北向，标注"不适用" |
| sector_valuation 无数据 | 估值维度仅做绝对值参考，标注"无行业对标" |
| 某字段含`[TIMEOUT]` / `[ERROR]` | 该子项标注"数据获取失败"，权重均分到同维度其他子项 |
