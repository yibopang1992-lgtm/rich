# HotMoney Scanner — 游资短线选股

## 前置依赖

本 Skill 依赖 `westock` CLI。未安装时先执行：

```bash
bash ~/.codebuddy/skills/westock-data/scripts/setup.sh
westock --help
python3 --version
```

---

## 使用方式

### 第一步：调用 Python 脚本批量采集全市场数据

```bash
# 收盘后分析（推荐，数据最完整，含龙虎榜）
python3 ~/.codebuddy/skills/hotmoney-scanner/scripts/collect_hotlist.py

# 历史复盘（注意：历史模式下龙虎榜不可用，第三步标的评分将跳过）
python3 ~/.codebuddy/skills/hotmoney-scanner/scripts/collect_hotlist.py --date 2026-08-11

# 结果保存到文件
python3 ~/.codebuddy/skills/hotmoney-scanner/scripts/collect_hotlist.py > /tmp/hotlist_data.json
```

> ⚠️ **历史复盘限制**：`westock lhb` 不支持 `--date` 参数，历史模式下龙虎榜数据不可用，脚本会在 `meta.note` 中标注，AI 分析时应跳过第三步（标的评分），仅输出市场情绪和主线板块分析。

脚本分三阶段采集：

| 阶段 | 数据 | westock 命令 | 说明 |
|------|------|-------------|------|
| 第一阶段（全并行） | 全市场涨跌分布 | `westock changedist` | **上涨占比**、11档区间分布、两市成交额 |
| 第一阶段（全并行） | 涨跌停家数 | `westock market-overview --type updown` | **涨停/跌停家数**、多周期上涨家数趋势 |
| 第一阶段（全并行） | 大盘画像总评 | `westock market-overview` | 14维度得分 |
| 第一阶段（全并行） | 三大指数行情 | `westock quote sh000001,sz399001,sz399006` | 上证/深成/创业板 |
| 第一阶段（全并行） | 板块涨幅/资金榜 | `westock sector ranking` | 行业+概念涨幅Top10+资金流入Top5+北向热门 |
| 第一阶段（全并行） | 热搜股/板块 | `westock hot stock/sector` | 舆论热度信号 |
| 第一阶段（全并行） | 宏观事件日历 | `westock macro indicator cn_calendar_future` | 今日起重要政策/数据发布事件 |
| 第一阶段（全并行） | 全市场游资龙虎榜 | `westock lhb --type hotmoney` | 仅当日，历史模式跳过 |
| 第一阶段（全并行） | 机构/活跃席位榜 | `westock lhb --type institution/activeseat` | 仅当日，历史模式跳过 |
| 第二阶段（批量） | 个股行情+日K | `westock quote <批量>` + `westock kline <代码> --period day --limit 6` | 龙虎榜标的的涨跌幅、是否涨停、近5日涨幅、52周高低 |
| 第三阶段（批量） | Top板块历史K线 | `westock kline <pt代码> --period day --limit 5` | 判断板块是否连续上涨 |

## AI 分析框架

拿到 JSON 数据后，按以下四步逐步分析。

> **非交易日**：若 `data.error` 字段存在，直接输出提示信息，终止分析。
> **历史复盘**：若 `meta.is_history_mode == true`，跳过第三步，仅输出第一、二步结论。

---

### 第一步：市场情绪定性（Go/No-Go 门）

> **若情绪等级为"退潮"，直接输出空仓建议，终止后续分析。**

#### 数据字段对应关系（修复 #3）

| 指标 | 读取字段 | 来源命令 |
|------|---------|---------|
| 上证涨跌幅 | `market.quote_sh` → `changePercent` | `westock quote sh000001` |
| 涨停家数 | `market.updown` → 涨停行 count 列 | `westock market-overview --type updown` |
| 跌停家数 | `market.updown` → 跌停行 count 列 | `westock market-overview --type updown` |
| 上涨占比 | `market.changedist` → 上涨占比情绪文案/家数 | `westock changedist` |
| 涨跌区间分布 | `market.changedist` → 11档区间 | `westock changedist` |

> ⚠️ `changedist` 和 `updown` 含义不同，不要混用：
> - `changedist`：截面的涨跌幅**区间分布**（>7%有多少家、5~7%有多少家……），用于读**上涨占比**
> - `market-overview --type updown`：**涨停/跌停的绝对家数**，用于判断赚钱/亏钱效应

#### 情绪等级判定

| 等级 | 条件 | 操作建议 |
|------|------|---------|
| 🔥 亢奋 | 涨停≥60家，上涨占比>65% | 谨慎追高，防次日高开兑现 |
| ✅ 活跃 | 涨停30~60家，上涨占比55%~65% | 正常操作，优选龙头 |
| ⚠️ 分歧 | 涨停15~30家，上涨占比45%~55% | 仅操作确定性最强标的 |
| ❌ 退潮 | 涨停<15家 **或** 跌停>20家 | 空仓观望，不操作 |

---

### 第二步：主线题材识别

从以下三个维度交叉验证：

#### 2.1 板块涨幅与资金流入（`sector.ranking`）

- 行业涨幅 Top3 + 概念涨幅 Top3 → 记录板块名和涨幅
- 行业资金流入 Top3 + 北向热门板块 → 记录资金口径
- **双上榜（涨幅+资金）的板块** → 升级为"主线候选"

#### 2.2 板块热搜度（`sector.hot_sector`）

- 热度排名前10与涨幅榜交叉
- **涨幅+资金+热度三榜齐出** → 确认为"主线板块"

#### 2.3 龙虎榜题材集中度（`lhb.hotmoney`）

- 游资活跃标的所属板块集中度
- 同一板块上榜股票≥3只 → 该板块游资共识强

#### 2.4 板块连续上涨判断（`sector.klines`，修复 #4）

读取 `sector.klines` 中各板块最近5根日K，计算连续上涨天数：
- 连续上涨≥3日 → 板块过热，后续在维度 4 扣分
- 连续上涨≥5日 → 高度警惕兑现风险，降级为"候选"

**输出**：主线板块清单（已确认/候选/过热）、板块强弱排序。

---

### 第三步：标的筛选与评分

> ⚠️ **历史复盘模式下跳过此步**（龙虎榜无数据）。

对 `lhb.codes` 中的所有标的进行四维打分（满分100）：

#### 维度 1：游资痕迹强度（35分）

| 信号 | 分值 | 数据字段 |
|------|------|---------|
| 游资席位净买入 | +20 | `lhb.hotmoney` 中该股游资合计净买入为正 |
| 知名游资席位（活跃席位榜） | +10 | `lhb.activeseat` 中出现 |
| 机构与游资同向买入 | +5 | `lhb.institution` 中机构也净买 |
| 游资净卖出 | -20 | 出货信号，强制降级 |
| 机构大额净卖出 | -15 | 机构主动减持 |

#### 维度 2：题材主线契合度（30分）

| 信号 | 分值 | 数据字段 |
|------|------|---------|
| 所属"主线板块" | +20 | 第二步确认的主线 |
| 所属"候选板块" | +10 | 第二步候选板块 |
| 热搜股票榜在列 | +5 | `hot.stock` 中出现 |
| 孤立题材、无板块共振 | -10 | 单兵作战 |

#### 维度 3：筹码结构与位置（20分）

读取 `stocks.quotes`（批量行情）和 `stocks.klines`（每只6根日K）：

| 信号 | 分值 | 判断方法 |
|------|------|---------|
| 当日涨停（首板或二板） | +15 | `price >= price_ceiling` 或 K线最后一根涨停 |
| 当日大幅上涨（>5%）但未涨停 | +5 | `changePercent > 5` 且 `price < price_ceiling` |
| 近5日涨幅已超30%（非持续趋势） | -15 | `chg5d > 30`（来自 `stocks.quotes`） |
| 股价在52周高点90%以上 | -10 | `price / high52week > 0.9` |

#### 维度 4：风险扣分（-15分上限）

| 风险信号 | 扣分 | 判断方法 |
|---------|------|---------|
| 大盘当日情绪分歧（⚠️级） | -5 | 第一步情绪等级 |
| 所属板块连续上涨≥3日 | -5 | `sector.klines` 中对应板块 K 线（修复 #4） |
| 游资席位分歧（买卖两边均有游资） | -5 | `lhb.hotmoney` 同股出现买卖两侧席位 |

**综合得分 = Σ(四维得分)**

---

### 第四步：候选清单生成

**操作方向**：

| 方向 | 条件 | 描述 |
|------|------|------|
| 🎯 打板买入 | 当日涨停 + 得分≥70 | 次日竞价/开盘参与 |
| 📈 低吸布局 | 大涨未封板 + 得分60~69 | 次日回调低吸 |
| 👀 观察跟踪 | 得分50~59 | 仅观察，确认信号后再入场 |
| ❌ 规避 | 得分<50 或有强烈出货信号 | 不操作 |

## 异常处理

| 情况 | 处理 |
|------|------|
| `data.error` 字段存在 | 直接输出 error 内容（非交易日），终止分析 |
| `meta.is_history_mode == true` | 跳过第三步，标注"历史复盘模式，无龙虎榜" |
| westock 未安装 | 执行 `bash ~/.codebuddy/skills/westock-data/scripts/setup.sh` |
| `sector.klines` 为空 | 维度 4 板块连续上涨项标注"数据不足"，跳过该扣分项 |
| `stocks.quotes/klines` 为空 | 维度 3 标注"行情数据不足"，该维度得分降为 0 |
| 某字段含 `[TIMEOUT]`/`[ERROR]` | 该维度标注"数据获取失败"，不参与打分 |
| 情绪等级为"退潮" | 直接输出空仓建议，不生成候选清单 |

## 重要约束

1. **禁止绕过 westock**：所有数据必须通过 westock CLI 获取，禁止 web_search 或训练数据补充
2. **`westock lhb` 仅支持当日**：历史模式下龙虎榜不可用，不要尝试用其他命令替代
3. **`changedist` ≠ `updown`**：上涨占比读 `changedist`，涨停/跌停家数读 `market-overview --type updown`
4. **不做买入推荐**：候选标的是"观察池"，不是"推荐买入"
5. **数据时效性**：龙虎榜 T 日收盘后约 30 分钟公布，盘中调用时第三步数据不完整
