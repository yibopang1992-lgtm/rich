# 盘中动态与资金成本框架

用途：用于短线板块、涨停接力、补涨、高低切换和中军趋势分析。只作为研究和决策支持，不构成投资建议。

## 核心原则

- 情绪锚不等于最佳买点。龙头用于确认板块强弱，真正高弹性机会可能在低位修复、20cm弹性、交叉题材或中军承接。
- 短线选股顺序应为：先确认板块逻辑和资金留存，再观察情绪龙/中军确认方向，最后在涨停池或强势池中筛选抛压更小、承接更强、仍有空间的候选。
- 收盘后排序只能生成观察清单，不能替代次日竞价和开盘确认。
- 次日盘中若资金选择与前一日排序冲突，应以实时竞价、主动拉升、VWAP承接和板块扩散为准。
- 资金成本要分层：低浮盈锁仓票适合看持续；低于20日成本的超跌修复票适合看爆发；高浮盈高换手票优先标记兑现风险。

## 必算指标

对涨停票、连板票、补涨票和中军，尽量计算或估算：

- 5日/10日/20日成交量加权成本：用收盘价 * 成交量的加权均价近似。
- 当前价相对20日成本浮盈：`(price / vwap20 - 1)`。
- 当前价相对10日成本浮盈：衡量近期接力资金成本。
- 当日成交额、换手率、成交额/流通市值。
- 当日成交量相对前5日均量。
- 封单金额/当日成交额。
- 首封时间、开板次数、是否午后板。
- 20日/60日高低点和上方套牢区。
- 龙头、分支龙、20cm核心、中军、交叉题材、后排跟风的角色。
- 抛压评估：上方套牢盘距离、前高压力、近期大阴线成交密集区、历史涨停炸板区、当日开板次数、封单衰减、龙虎榜/大资金兑现痕迹。

## 资金行为推断

| 结构 | 推断 | 风险 |
|---|---|---|
| 相对20日成本浮盈 0%-8%，低/中换手，封单强 | 可能仍是锁仓或继续做高阶段 | 若龙头无溢价则失效 |
| 相对20日成本低于0%，当日主动涨停 | 超跌修复/低位点火，可能成为高低切弹性 | 若无板块确认，容易一日游 |
| 相对20日成本浮盈 15%+，高换手，反复开板 | 老资金已有较厚利润，接力和兑现并存 | 次日高开低走/炸板风险高 |
| 20cm强于10cm且创业板/科创风险偏好高 | 弹性资金偏好升温 | 波动大，不能套用普通10cm连板稳定性 |
| 中军放量红盘但未涨停，价接近20日成本 | 可能是趋势资金铺垫/承接 | 若情绪龙断板且中军破VWAP，降级 |
| 涨停股上方前高远、套牢成交少、开板少、封单稳定 | 抛压较小，次日连板阻力相对低 | 若板块退潮或竞价弱，仍会失效 |
| 涨停股刚到前高/成交密集区，封单弱或多次开板 | 抛压正在释放，资金需要更大成本维持 | 次日容易分歧或被同板块低位票替代 |

## 次日动态切换

开盘必须重新排序，不沿用昨晚静态排名：

1. 9:15-9:25 看竞价：龙头是否有合理溢价，后排是否批量弱，20cm弹性是否主动。
2. 9:30-9:45 看主动性：谁先站上VWAP、谁先封板、谁弱转强。
3. 若情绪锚不封板但稳住红盘，且低位/20cm/交叉题材主动拉升，应从“龙头晋级”切到“高低切/弹性修复”。
4. 若情绪锚低开低走、后排无溢价、中军破VWAP，停止后排补涨推演。
5. 若新热点资金流、涨停数、20cm数量明显强于原方向，降低原方向候选权重。

## 龙头竞争期执行规则

在主线竞争期，持有的核心票先判断“是否仍在竞争”，再决定卖出，
不要先用持仓成本或盘中浮盈做决定。

仍在竞争时，倾向继续观察或分批处理：

- 板块仍稳定向上，涨停数或强势股没有明显塌缩。
- 个股仍是板块最高板、分支最高板、最早封板、或最强辨识度之一。
- 个股回落但不破 VWAP，或破 VWAP 后能快速收回。
- 同板块中军/容量锚仍红盘或站上 VWAP。
- 同主线其他分支龙仍在晋级，说明资金未离开主线。

竞争失败时，才降低权重或退出：

- 个股被同板块更强标的卡位，且自身无法修复。
- 个股放量跌破 VWAP，反抽不能站回。
- 龙头和中军同步走弱，后排无溢价或批量炸板。
- 新主线明显更强，原方向资金被抽走。
- 个股从龙头候选降级为后排跟风，只剩套利属性。

核心原则：龙头候选的胜负比通常不对称。若主线未退潮，过早卖出
可能只是少亏或少回撤几个点，却放弃胜出后的 10%-20% 溢价；但
后排跟风不适用此规则，仍按套利和风险纪律处理。

## 主线组合与错过打板

主线确认后，应按角色构建观察清单，避免只押单票或卖飞后空仓：

- 情绪龙：优先观察高度、封板质量、是否带动后排。
- 分支龙：观察资金切到哪个细分方向。
- 中军/容量锚：观察趋势资金和机构容量是否承接。
- 低位补涨：仅在情绪龙、中军、分支龙未失效时考虑。

如果错过当日最强板：

- 不追已经过度一致且无换手机会的缩量板。
- 等炸板回封、分歧转一致、或次日竞价/VWAP确认。
- 可转向同主线的分支龙、中军、低位补涨，但必须确认板块仍强。
- 不要因为卖飞原持仓而临时追弱后排；先重新按板块和角色排序。

## 选股分层

- **情绪锚**：确认板块，不自动视为买入候选。看竞价、VWAP、溢价、是否带动后排。
- **低抛压连板候选**：在板块逻辑成立、情绪锚不破、涨停联动存在后，从涨停池里优先找上方套牢少、封单稳定、开板少、相对20日成本浮盈不极端、当日换手充分但未失控的票。
- **高低切弹性**：前日弱或未充分表现、相对20日成本不高或低于20日成本、次日主动弱转强。
- **20cm核心**：风险偏好升温时提高权重，但必须看封板/承接和板块中军。
- **交叉题材**：AI应用+机器人、软件+智能制造、芯片+机器人等可能比纯度票更容易被资金包装；不要被纯度过滤误杀。
- **中军**：用于判断持续性。中军放量红盘代表趋势资金承接；中军集体破VWAP代表情绪票风险升高。
- **后排**：只在龙头、中军、分支龙同时确认时才观察；高潮次日默认降级。

## 成交额、换手率、流通市值解释

- 成交额/流通市值约等于实际换手压力的资金强度。百亿流通市值、15亿成交、10%换手代表当天筹码交换充分，资金分歧明显但仍有承接。
- 5%-12%换手常见于健康分歧或趋势换手；低于3%偏锁仓或筹码稀缺；高于20%多为强博弈和兑现/接力混合。
- 成交额过小的涨停更容易被单一资金影响；成交额过大且封不住，说明承接成本高、次日兑现压力大。
- 高换手不一定坏，关键看结果：放量后站稳/回封是换手成功；放量后冲高回落是兑现占优。

## 低抛压候选筛选顺序

1. 板块确认：板块资金净流入、涨停数量、上涨家数、情绪龙和中军至少有一组确认。
2. 情绪确认：情绪龙不明显负反馈，中军不破VWAP，分支龙或20cm弹性仍有溢价。
3. 涨停池筛选：优先看首封早、开板少、封单/成交额较高、成交额足够但不过度爆量的票。
4. 抛压筛选：避开刚触及前高、历史放量套牢区、连续高浮盈且换手失控的票；优先上方空间清晰、前期筹码交换充分、当日封板成本不高的票。
5. 次日验证：竞价有溢价但不过度一致，开盘快速站稳VWAP，回踩不破昨日涨停价或当日均价，板块内仍有新增助攻。
6. 失效处理：情绪龙低开低走、中军破VWAP、同板块涨停股批量炸板、候选跌破当日VWAP且无法收回，低抛压假设失效。

## 卖出复盘检查

复盘卖出动作时，必须区分三类错误：

- 选错方向：板块已退潮或资金明显流出，卖出正确。
- 卖错角色：把仍在竞争的龙头候选当普通套利票卖出。
- 错过切换：卖出掉队票可以，但没有切到同主线更强的分支龙或中军。

对每次卖出记录：

- 卖出时板块是否仍稳定向上。
- 个股是否仍有龙头候选资格。
- 是否有明确失效信号，而不是只因已有利润或害怕回落。
- 同主线是否已有更强标的可切换。
- 卖出后是否错过主线继续扩散。

## 输出要求

涉及涨停、连板、补涨或次日策略时，必须输出：

- 情绪锚和最佳进攻票是否分离。
- 候选的资金成本：5/10/20日成本或说明缺失。
- 当前价相对20日成本浮盈。
- 当日换手率、成交额、封单/成交额、开板次数。
- 是锁仓、接力、低位修复、20cm弹性、交叉题材，还是高换手兑现风险。
- 抛压结论：上方压力、套牢区、封单稳定性、开板次数、次日是否需要弱转强验证。
- 对已持有核心票，判断其是仍在竞争、已经掉队、还是仅剩套利属性。
- 若错过最强板，给出同主线替代观察路径，而不是追弱后排。
- 盘中触发条件和失效条件。
