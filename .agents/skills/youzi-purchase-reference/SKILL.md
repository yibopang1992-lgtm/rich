# 游资购买参考

将新龙虎榜截图与已核验历史样本对照，识别多席位共识、兑现风险和可能的早期铺垫。仅作A股研究与决策支持，不构成投资建议，不承诺收益。

## 强制数据纪律

1. 先核验数据，再分析风格。不得凭股票简称、颜色或记忆猜测代码、股价、行业、买卖方向或金额。
2. 对当前行情或新截图分析，先使用 `ashare-refresh-before-analysis` 刷新 rich 服务；历史日线优先用新浪或 Baostock，北交所用新浪。记录来源和抓取时间。
3. 将龙虎榜金额视为席位汇总金额，不视为逐笔成交价。收益只能标为“预计/估算”。
4. 单日榜单用当日市场 VWAP；“3日”榜单用截至榜单日最近三个交易日的市场 VWAP，并将收益置信度降为低。
5. 同一游资同一股票按 FIFO 匹配后续卖出。样本窗口内没有先前买入的卖出，不反推成本，不计算收益。
6. 截图被头像、裁切或压缩遮挡时保留缺失值和质量标记。不得补造金额。
7. 龙头标的只用于观察板块强度，不自动列为买入候选。

## 历史参考库

按任务需要读取以下文件，不要一次性加载全部明细：

- `references/trader_profiles.csv`：先按新图中的游资名筛选。字段包含买入样本、股票数、买入额、可观测退出样本、1日兑现率、预计胜率、收益中位数、主要行业、打法标签和置信度。
- `references/transactions.tsv`：需要核对某游资、某股票、某行业或买卖时间序列时筛选。共 612 条操作记录。
- `references/investments.csv`：需要核对某游资历史收益、持有周期、已实现/浮动收益时筛选。共 360 笔买入投资。
- `references/consensus.csv`：需要查历史同日多席位买入时筛选。
- `references/eastmoney_seats.tsv`：需要查东财拉萨买方席位数量时筛选；没有金额，不计算收益。
- `references/stock_map.csv`：股票简称、代码、规范名和行业映射。
- `references/summary.json`：样本时间、行数、行情来源和计算口径。
- `scripts/build_reference.py`：扩充或更正样本后，重新抓取行情并生成收益、画像和共识数据。

基线样本截至 2026-08-15 生成，覆盖 2026-07-20 至 2026-08-14，共 291 个可识别股票、5,738 条日线、360 笔买入投资。样本期短，风格结论必须带样本量和置信度。

## 新截图分析流程

### 1. 提取与复核

逐张放大读取日期、游资/席位、买卖方向、股票、金额和“3日”标识。将 OCR 只作为初稿，人工复核每一行。把不确定项标为 `obscured`、`partially_obscured` 或 `source_error`。

用当日东方财富龙虎榜详情与 A 股代码表纠正易混字，例如公司更名、空格简称、ST/XD 前缀。若无法唯一匹配，停止该条目的收益和板块判断。

### 2. 识别多游资共识

按“日期 + 股票”统计不同买方游资数，并再按行业/题材聚合：

- 2–3 名不同游资同日买入：`多游资共识`。
- 4 名及以上同日买入：`多游资强共识`。
- 只有一名席位：`单席位`，不能称为共同认可。
- 拉萨席位数量只作散户活跃度/拥挤度旁证，不与实名游资简单相加。

同时检查相反证据：同日或次日是否有历史买方卖出、板块资金流是否转弱、是否已经连续高潮。共识不是确定性上涨信号。

### 3. 判断快速套利/兑现风险

对新图每名游资，读取 `trader_profiles.csv` 和相关历史明细：

- `1日兑现率 >= 50%` 且可观测退出样本 `>= 3`：标记“次日/短线兑现风险高”。
- 首次卖出中位数 `<= 3天`：标记“1–3日短波段”。
- 同一游资曾在同一股票或同类行业 1 日内反向卖出：提高风险一级。
- 买入是“3日榜单”、金额显著放大、同股已有多席位拥挤或次日出现卖出：提高风险一级。
- 退出样本少于 3 或总买入样本少于 6：不得给高置信风格标签。

用“需防范兑现”“历史样本显示偏短”表述，不写“必砸盘”“一定套利”。

### 4. 判断可能的铺垫初期

只有同时满足下列证据时，才标记“可能铺垫初期”：

- 该股票/题材在新样本中首次或较早出现，尚未形成 4 席位以上拥挤；
- 买方游资历史首次卖出中位数较长，或同类方向曾分批买入；
- 当前不是“3日累计大涨”后的首次公开榜；
- 资金流、成交额和板块成员扩散支持，而不是单票孤立异动。

任一条件不满足时改为“待确认”。触发条件可写为次日板块净流入延续、核心股不破 VWAP/前低、出现第二名独立游资确认；失效条件写为首批买方反向卖出、板块净流出、核心股跌破关键位或数据无法刷新。

### 5. 识别板块周期

将同一题材的行为分为：

- `试探/铺垫`：少数席位首次买入、金额分散、板块未拥挤。
- `扩散/共识`：不同风格游资连续买入多个板块成员。
- `高潮/拥挤`：同日多席位集中、3日榜单频繁、拉萨席位显著增加。
- `兑现/退潮`：早期买方卖出，新买方接力但板块资金转弱。

必须列出支持证据、相反证据、数据时间戳和置信度。

## 输出格式

按以下顺序回答：

1. `数据状态`：截图日期、行情/资金流时间、来源、缺失和降置信项。
2. `多游资一致方向`：股票、板块、买方名单、人数、金额、周期位置、相反证据。
3. `快速兑现风险`：游资、股票、历史1日兑现率、退出样本数、历史持有中位数、触发与失效条件。
4. `可能铺垫初期`：股票/板块、为什么是早期假设、需要什么确认、何时失效。
5. `逐游资参考`：每人打法、偏好行业、持有/兑现节奏、样本量、置信度。
6. `风险提示`：明确研究用途、不构成投资建议；数据不全时降低结论强度。

对每个结论都给“原因、风险、触发条件、失效条件”。不要把估算收益写成真实账户盈亏。

## 扩充样本

将新截图结构化追加到 `references/transactions.tsv`；拉萨买方席位追加到 `references/eastmoney_seats.tsv`。保留源图片名和质量字段。运行：

```bash
python scripts/build_reference.py --start YYYYMMDD --end YYYYMMDD --output-dir /absolute/output/path
```

检查 `mapping_failures.csv`、`price_fetch_failures.csv`、`unmatched_sales.csv` 和 `summary.json`。只有代码匹配失败和价格抓取失败均为 0，且遮挡项已披露时，才更新 `trader_profiles.csv`、`investments.csv`、`consensus.csv`、`stock_map.csv` 和 `summary.json`。
